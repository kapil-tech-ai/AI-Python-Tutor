# AI Python Tutor 🐍

A web-based AI Chatbot built using **Python**, **Streamlit**, and the **Groq API**. 

## Features
- **Interactive UI:** A clean, WhatsApp-like chat interface.
- **Strict Persona:** Acts as a strict Python teacher.
- **Memory:** Remembers the context of the conversation.
- **Fast Responses:** Powered by Groq's ultra-fast LLMs.

## How to Run
1. Install the required libraries:
   `pip install -r requirements.txt`
2. Replace the API key in the code with your own Groq API Key.
3. Run the app:
   `streamlit run python strict.py`
